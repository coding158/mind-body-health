## 一、原文（帛书甲本，对照传世第 50 章后段）

> 蓋閳善執生者，
> 陵行不辟矢虎，
> 入軍不被甲兵。
> 夫无所椯其角，
> 虎无所昔其蚤，
> 兵无所容其刃。
> 夫何故也？以其无死地焉。

本章在干昌新的德经分章中列**第十八章**，对应传世本第 50 章的后段（前段即本系列第十七章）。

**本章是改笔较多的一章**，与传世本逐处对照如下：

| 传世本 | 勘定本 | 性质 |
|---|---|---|
| 聞 | 閳 | 干氏勘定用字（**第三次出现，原书仍无注疏**，见第十五章说明） |
| 攝生 | 執生 | 用字不同，训释亦不同 |
| 陸行 | 陵行 | 用字不同 |
| 不遇**兕**虎 | 不辟**矢**虎 | 遇→辟；兕→矢 |
| **兕**無所投其角 | **夫**无所椯其角 | **本章最大的争点，详见下节** |
| 措 | 昔 | 原书注疏 2 |
| 爪 | 蚤 | 原书注疏 3 |

**关于「椯」**：此字与传世本「投」的差别，原书勘误列未作说明，本文标为待核，不强解。

## 二、本章最重要的一件事：一个字位，干氏自己的两部书打架

传世本作「**兕**無所投其角」——兕是犀牛，犀牛用角来抵。这个读法两千年来没有异议。

干昌新在两部著作里对这个字位给出了**两套互不相容的主张**：

**《破译〈老子〉祖本》（p.170 注疏 1）的主张**——这是一条三层递变的判断：

> 帛书图版上此字清晰可辨，本是「**夫**」；甲本释文误认作「**矢**」；整理小组又在释文上赞注为「**兕**」。三个字意义全然不同，属明显的篡改。

**《老子人体生命科学》（「总结」篇第 7 条，明标本章章号）的主张**——这里他直接把经文写作「**矢**」，训为箭，取其**指向目标而迅疾**的比喻义（引《释名》「矢，指也」），并只说后世传抄本被改成了「兕」。**全篇没有提到「夫」这个主张。**

也就是说：

| | 《破译》 | 《生命科学》 |
|---|---|---|
| 原字是什么 | **夫** | **矢** |
| 「矢」的地位 | 释文的**误认** | 就是**原字** |
| 「兕」的地位 | 释文之上再加的赞注 | 后世传抄的篡改 |
| 理由 | 图版可辨 | 逐字解密＋整句译文 |

**这不是"字形确认"与"字义确认"的层次差别，而是同一位作者在两本书里对同一个字位给出了不同的正字。**

本文的处理是：**并存两说，不替他裁断。** 上节原文栏依《破译》作「夫」（因该书专述本章勘误，权重较高），第三节的白话则依《生命科学》取「矢」义（因该书有完整的逐字解密可循）。这样处理会造成本文自身的一处不齐整——**我们保留这处不齐整，因为它如实反映了材料的状况。**

**这一处也是最容易被外部检验的**：两说都可以拿帛书篆文影印图版直接核对。哪一说成立，不取决于谁的推理更漂亮。

## 三、关键字义（转述干昌新训释，逐条标出处）

| 字/词 | 修炼学读法（转述） | 出处指引 |
|---|---|---|
| 善 | **特殊营养**（他特别说明，其中兼含营养作用与准平作用） | 《生命科学》「总结」篇本章条目；道经既有成例 |
| 執 | **捕捉**——捕捉大脑高功能 | 同上。**不是**传世本「攝生」的"摄养" |
| 生 | 产出 | 同上 |
| 陵 | **崇高**（本义是大的土山，由此引申） | 同上（引《说文》「陵，大阜也」） |
| **行** | **人体置备了双重的知感功能**——日常知感与特异知感，"左右并举" | 同上（引《韵会》：行是左脚一步、右脚一步，两步俱举才成其为行） |
| 辟 | **法度、规范** | 同上（引《说文解字注》「辟，法也」） |
| 矢 | 箭，喻高功能的**指向目标与迅疾** | 同上（引《释名》「矢，指也」）。字位争议见第二节 |
| 虎 | 山中兽类之君，喻高功能是人体的**功能之首** | 同上（引《说文》「虎，山兽之君」） |

| **蚤** | 啮人的跳虫。经传中多假借它来写「早」字——但他强调：**假借归假借，原文不可更改** | 《破译》p.170 注疏 3 |
| 无 | 本章四见，均取语法上的"没有" | 本文判定，信心 high |
| 不 | 「不辟」「不被」之「不」均是真否定 | 本文判定，信心 high |
| 椯 | **待核**，不强解 | 原书勘误列未注 |

### 「行」这一条值得单独看

《韵会》解释「行」这个字：它的左半是「彳」，表示左脚迈出一步；右半是「亍」，表示右脚迈出一步；**左右两步都迈出来，才叫作"行"**。

干氏抓住这个"左右俱举"的结构，把「行」训作**人体同时置备了两重知感功能**——日常的那一重，与特异的那一重。一个字的构形，被读成了"两套功能并行"。

这条训释是否成立可以再议，但它示范了这个体系的典型手法：**从字的构造里读出功能的结构**。本系列此前的「爲」（母猴抱雏之坐形）、「五」（两横夹一交叉）都属同一路数。

## 四、逐句白话（本文作者按上表字义自行组织的表达）

> 说明：本节第一句依《生命科学》的逐字解密组织，取「矢」；第三句的字位争议见第二节。

**蓋閳善執生者，陵行不辟矢虎。**
据特异信息所传报：凡是凭特殊营养把「产出」捕捉住的那种修炼者，已经把那种崇高的、左右两边同时并举的功能置备起来了；这样的人无须外加规范，本身就有如箭一般直指目标的迅疾，以及山兽之君那样的功能之首的品质。

**入軍不被甲兵。**
进入军阵，也不为甲兵所伤。

**夫无所椯其角，虎无所昔其蚤，兵无所容其刃。**
（那一方）无处施其角，虎无处把「昔」（乾肉般日晒砧宰的煎迫）加于其爪，兵刃无处容其锋。

**夫何故也？以其无死地焉。**
这是什么缘故？因为他没有「死地」。

## 五、全章义理串讲（本文归纳）

传世本这一段，是《老子》里最常被引用的"不死"段落：

> 善摄生者，陆行不遇兕虎，入军不被甲兵。兕无所投其角，虎无所措其爪，兵无所容其刃。

历来读作：善于养生的人，走在陆地上碰不到犀牛老虎，进入军阵不被兵器所伤——因为他身上没有可以致死的地方。这是一段关于**避险**的描述。

干昌新的读法，把"避险"整个换成了"**具备**"。

**换的支点是「辟」字。** 传世本作「不**遇**兕虎」——遇是遭遇，所以是躲开了。勘定本作「不**辟**矢虎」，而「辟」他训作**法度、规范**。于是这半句不再是"碰不到猛兽"，而是：**不必外加规范，就已经具备了"矢"与"虎"所比喻的那两种品质**——如箭一般的迅疾指向，与如山兽之君一般的功能之首。

猛兽从"要躲开的危险"，变成了"用来比喻的品质"。方向正好相反。

**「執生」也是同一方向的改动。** 传世本「攝生」是养生、摄养；勘定本「執生」，干氏训作**以特殊营养把"产出"捕捉住**。一个是保养已有的，一个是捕捉新生的——前者守成，后者进取。

**中段那三句，则回到了"受困"的意象。** 特别是「昔」字：他引《说文》说这个字从残肉，靠日晒而成，与砧板同意；天天被拿去晒、拿去割，在一个活物是最难堪的处境。他用这个字**比喻人在修道之前，体内潜能所处的境况**。传世本此处作「措」（安放），意思平淡；一改成「昔」，就带上了煎迫感。

**末句「以其无死地」需要与前一章连读。** 本系列第十七章里，「死」训作「定」的意识功能态，「地」训作人体的代词。但在本章，「死地」他没有另作专训，仍按通行的"致命之处"来理解。**同一个词组，前后两章取义不同**——这一点本文如实标出，不替他统一。

### 最后：一条比任何训释都重要的态度

本章注疏 3 讲「蚤」字，说得很清楚：这个字在经传里常被假借来写「早」——**但即便假借关系成立，原文也不能改。**

这句话看起来只是一条小注，其实是整个勘定工作的立场所在。历代整理古书，遇到假借字往往径直改成通行字，理由是"意思一样"。干氏的做法相反：**假借关系成立，只说明可以这样读，不等于可以这样写。** 原字必须留在原处。

他在本系列各章反复出现的那句判断——"两字意义完全不同"——依据的正是这条立场。理解这一点，才谈得上理解他为什么要花力气去争一个「兕」还是「矢」、「措」还是「昔」。

而也正因如此，本章第二节那处**他自己两本书的冲突**才格外要紧：一个把原字看得如此之重的体系，在自己最看重的地方出现了内部分歧。**本文如实呈现，不作调和。**

## 六、实践对照（Layer 4 · 仅供现代读者理解参考，非原文含义）

- **"避开危险"与"具备品质"**：这是两种很不一样的安全观——一种靠回避，一种靠自身状态。本章勘定读法取后者。此处仅作理解参考，原文所指是特定功法状态，非一般处世之道。
- **「昔」的意象**：把修炼之前的状态比作被曝晒宰割的乾肉，是个相当强烈的说法。读者不必照单接受，但它提示：这个体系认为修炼前后的差别是**处境上的**，不只是感受上的。
- **关于内部矛盾**：本章第二节呈现的是一个解释者自己前后不一的例子。**遇到这种情况时，最不该做的是替他选一个再假装没有分歧。** 一个体系的可信度，恰恰体现在它的矛盾是否被如实记录下来。这一条对读者判断任何学说都适用。
