## 一、原文（帛书甲本，对照传世第 50 章前段）

> 出生入死，
> 生之徒十有三，
> 死之徒十有三，
> 而民生生動皆之，
> 死地之十有三。
> 夫何故也？以其生生也。

**本章的证据结构**：原书**没有列出任何勘误条目**——用字上与传世本没有分歧。但《老子人体生命科学》对本章给出了**完整的逐字解密**，而且同一段解密在该书中**两次独立引用**。所以这是一个"零改笔、强解说"的样本：改动为零，读法却与通行本相去最远。

**一处断句不同**：通行本读作「而民之生生，动皆之死地，亦十有三」；勘定本读作「而民生生動皆之，死地之十有三」。断在哪里，直接影响后半章怎么讲。

本章在干昌新的德经分章中列**第十七章**，对应传世本第 50 章的前段（后段即本系列第十八章）。

## 二、关键字义（转述干昌新训释，逐条标出处）

| 字/词 | 修炼学读法（转述） | 出处指引 |
|---|---|---|
| **死** | **「定」的意识功能态**——不是死亡 | 《生命科学》本节；该书中两次分别引用，均如此明训 |
| 出 | 出达（引《说文》「出，进也」，取草木滋长上出之象） | 同上 |
| 入 | 自外而入于内（引《说文解字注》「入，内也」） | 同上 |
| 生 | 进，引申为**产出**——指大脑高功能的产出 | 同上（引《说文》「生，进也」） |
| 徒 | **稳步前行**（引《说文》「徒，步行也」） | 同上。**不是**通行读法的"类属"或"十分之几" |
| **十** | **完满具足**——引《说文解字注》「十，数之具也」，并取古人以东南西北中方位齐备为完备之意 | 同上 |
| **三** | **能量偕配阴阳**，即阴阳两种势力共存于同一统一体内 | 同上（引《说文解字注》所录「一生二，二生三」一段） |
| 有 | 特殊营养素、特殊能量及其功能转换 | 同上；道经既有成例 |
| 之 | **颊侧上出**——高功能自潜能中脱颖而出的那种生命现象 | 同上；道经既有成例 |
| 生生 | 阴阳加速变化，从而**形成并产出前所未有的东西**——落在人体上即特异功能。**不是**"厚养其生"或"贪生" | 同上（该体系的专用术语） |
| 民 | **气功修炼者** | 同上。**注意**：与本系列他章「民／百姓＝众潜能」的字面读法有别，此处依原书 |
| 地 | 人体的代词 | 同上（第二次引用中明训） |

> **本章的关键在「死」字。** 它在章内三见（入死／死之徒／死地），若全部读作死亡，本章就是一篇生死统计；若全部读作「定」的功能态，本章就是一篇功态描述。改动为零，落点却完全相反——这是本系列中"不改一字而全章易辙"最彻底的一例。

## 三、逐句白话（本文作者按上表字义自行组织的表达）

**出生入死。**
向外出达而有所产出；而由外向内进来的那些特异信息，是在「定」这一意识功能态里生成的。

**生之徒十有三，死之徒十有三。**
已经产出的「之」（颊侧上出，即脱颖而出的高功能）稳步前行；在特殊营养素、能量与功能转换三者都完备的条件下，体内能量与阴阳相配，从而化生出种种事物。

**而民生生動皆之，死地之十有三。**
而修炼者一味「生生」（阴阳加速变化，从而形成前所未有之物——也就是人体的特异功能），动辄就到这一步；「定」的功能态令人体产出「之」，同样在上述三者完备的条件下，能量与阴阳相配而化生万物。

**夫何故也？以其生生也。**
这到底是为什么？——因为阴性的那一面是在阴阳之间一种特殊的变化里，凭着「定而有识」的功能态，形成并产出了新的大脑高功能。

## 四、全章义理串讲（本文归纳）

### 先说那个两千年的公案

传世本第 50 章开头是《老子》最著名的疑难段落之一：

> 出生入死。生之徒十有三，死之徒十有三，人之生动之死地，亦十有三。

「十有三」到底是什么，历代注家至少给出过三种答案：有读作"十分之三"的，有读作"十三"并指为四肢九窍的，也有另立别解的。这场争论打了两千年，至今没有定论。争的焦点始终是同一个：**它是个数字，那么这个数字指什么。**

干昌新的读法**整个绕开了这场争论**——因为在他这里，「十有三」根本不是数字。

- 「**十**」不取数目十，取**完满具足**：《说文解字注》说十是数之具备，古人又以东南西北中五方齐备为完全，由此引申；
- 「**三**」不取数目三，取**阴阳偕配**：阴阳两种势力共存于一个统一体之内（这一读法与本系列第八章的「三」完全一致，两章互证）；
- 「**有**」不取"有无"之有，取该体系的既定专义：**特殊营养素、特殊能量及其功能转换**。

三个字合起来，「十有三」成了一个**由三个实词组成的短语**——大意是：在营养、能量与功能转换都完备的条件下，阴阳得以相配。它描述的是一种**状态的齐备程度**，而不是一个比例或一个数目。

这个处理值不值得接受，读者可以自己判断。但有一点值得注意：**它把一个数字难题转成了一个状态描述**，于是那个争了两千年的问题在这个体系里不再成立。一种解释体系的力量与风险，往往正在这种地方同时显现。

### 再说那个真正的翻转：「死」

本章「死」字三见。通行读法里它就是死亡，于是整章是在讲人的生死归属。

干氏把它训作**「定」的意识功能态**——那个在本系列中反复出现的、修炼进入定境的状态。这个读法在他书中出现过两次独立引用，依据算是扎实。

一字之转，全章换了话题：

| | 通行读法 | 勘定读法 |
|---|---|---|
| 出生入死 | 从生走向死 | 出达而产出；外来的特异信息生成于「定」态 |
| 死之徒 | 属于死的那一类 | 「定」态之下稳步前行 |
| 死地 | 死亡的境地 | 「定」态所归的人体 |

于是本章不再是一篇关于寿夭的统计，而是**一篇关于"定"这一功能态如何产出高功能的陈述**。首句「出生入死」也就不再是"从出生到死亡"，而是**一出一入的两个方向**：向外是出达产出，向内是信息归于定态。

### 「生生」不是贪生

末句「以其生生也」，通行读作"因为他太厚养自己的生命"——这是一句批评，历来与《老子》他处"益生曰祥""贵生"之诫连读。

干氏不从。「生生」在他这里是一个**专用术语**，指阴阳加速变化而形成、产生新的事物，落在人体上即**特异功能**。于是末句不是批评，而是**解释原因**：之所以会有前面那一切，是因为发生了「生生」。

这个改动的方向，与本系列此前遇到的几次是同一类型（第十章「天下希能及之矣」由感叹变成结果描述，第十四章「其知彌少」由贬义翻成褒义）：**凡通行读法读作警告或贬抑的地方，这个体系往往读作现象的记录。**

### 两处必须如实标出的地方

**其一，「民」字。** 干氏在本章明训「民」为**气功修炼者**。而在本系列其他章里，「民」「百姓」通常按众潜能的代称来读（如第十六章）。**同一个字，在他自己的书里前后取义不同。** 本文依原书，在本章取"修炼者"，但把这个不一致明白标出——不替他统一。

**其二，「地」字。** 本章「地」他训作**人体的代词**，是个宽泛的代称；而本系列他处「地」多落在腹底。两者并不冲突（腹底属于人体），但宽窄不同，本文一并记下。

## 五、实践对照（Layer 4 · 仅供现代读者理解参考，非原文含义）

- **"一出一入"的双向结构**：把首句读作出达与内入两个方向，而非一条从生到死的单向线，这个结构本身对理解练习有参考价值——多数练习确实是双向的，既有向外的展开，也有向内的收摄。此处仅作理解参考，非原文断言。
- **关于「十有三」的启示**：一个难题解不开时，有时问题出在**提问的方式**上——两千年都在问"这个数字指什么"，而这个体系的回答是"它不是数字"。这种转移对不对可以再议，但**先检查问题本身是否成立**，是个值得借鉴的习惯。
- **不把警告当结论**：本章通行读法里的批评意味（贪生），在勘定读法里消失了。读者遇到这类分歧时，宜留意：**是原文在批评，还是注家在批评？** 这两件事不总是一回事。
