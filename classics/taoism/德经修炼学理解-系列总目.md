## 一、这个系列在做什么

《老子》通行了两千年的读法，多把它当哲学书。干昌新先生（《破译〈老子〉祖本》等三部著作的作者）主张：**帛书《老子》原本是一部讲人体修炼的操作性文献**，许多今天读来玄虚的句子，在他的体系里都有具体所指——"天下"指人体的巅顶与腹底，"爲"指打坐调形的姿势，"德"指生命功能的哺育升登。

本系列不做真伪裁断，只做一件事：**把这套读法完整、可核查地呈现出来**——每个关键字的训释都标明出自哪本书、哪一页，属于原书实录还是本文推演。读者据此自行判断。

**每篇的固定结构（六段）：**

| 段 | 内容 | 性质 |
|---|---|---|
| 一 | 原文（帛书残缺情况一并说明） | 公版文本 |
| 二 | 关键字义表（逐条标出处） | **转述**干氏训释 |
| 三 | 逐句白话 | 本文作者组织的表达 |
| 四 | 全章义理串讲 | 本文归纳 |
| 五 | 实践对照 | **仅供现代读者参考，非原文含义** |
| — | 文末指路 | 原书信息 |

第五段"实践对照"始终单独标注、不混入原文含义——这是本系列的一条硬纪律。

> 个别篇会多出一节：当某处存在**必须单独交代的争议**时（如第十八篇的两书冲突、第二十篇的内部不一致），本系列不把它塞进串讲里含混带过，而是专列一节。遇到七段的篇目，多出来的那一节通常就是全篇最要紧的地方。

## 二、怎么读这个系列

**如果你只想读三篇**，建议这个组合：

1. **第一篇**——建立最多基础术语（上／下／德／不／有／无／爲），是全系列的地基；
2. **第十篇**——干氏解说最完整的一章，可以看清这套读法"讲到细处"是什么样子；
3. **第十七篇**——一个字都没改，读法却与通行本相去最远，最能看出这个体系的性格。

**顺读**（推荐初次完整阅读）：第一 → 第五十六篇。注意其中有一道分界：

| 篇次 | 原书依据 | 特点 |
|---|---|---|
| 第一～八篇 | 干氏为德经写有**"简略点评"**的部分（点评止于第八章） | 有整章的判断可循 |
| 第九～五十六篇 | **点评之后**——依据转为逐字解密、勘误注疏与字义带入 | 依据强弱差别更大，本系列逐篇标明 |

**查字**：直接看第四节《关键读法清单》，找到该术语的首见篇，跳过去读。

**看字库里没有的字**：第五节《字库外用字一览》。

**只想看"通行本改了哪些字导致读法全变"**：直接跳第六节。

**关于占位符**：这些符号是**本系列为方便阅读而设**，不是通用写法，也不是原书用的符号。同一符号在本系列内**始终指同一个字**（例如 △ 在第九、十五两篇是同一字；■ 在第二十二、二十八两篇是同一字，且原书自己注明互见；■ 与 □ 在第二十二篇同章出现，实心者为要塞住的那扇，空心者为被开启的那扇），但出了本系列就没有意义。各字的印刷字形见《老子如何修道养寿》附录所收的自创字表——**其中 ◆ 与 ▲ 不在该表内**，因为干氏并未把它们算作自造字。

> **这套自造字主张有两个软处，都在第二十六～二十八篇**：
> - **✱**（第二十六篇）——**性质存疑**：作者自己用了"可能是"，全书仅此一处，理由是《说文》未收、他书未见（这是**消极证据**）；
> - **✵**（第二十八篇）——**功能义空缺**：性质断定了、构形拆了，却只圈定"关乎人体生命"这一范围。
>
> 两者是**不同的**不完整：一个是"不确定它是不是"，一个是"确定它是、但没说清它是什么"。

**为什么要分两类**：说某字是"老子新造的"，与说某字"本来就有、只是被抄错了"，是两种强度完全不同的主张。前者需要解释这个字为何不见于他处，后者只需比对图版。**混着讲会虚增主张的强度**，所以本系列逐篇标明。

## 七、阅读时请注意的三件事

### （1）第一～四篇完成于本系列证据标注规范建立之前

本系列在整理过程中逐步建立了更细的**来源标注规范**：字义训释要区分「原书逐字实录」「注疏推论」「本文推演」，并对推演标注信心程度。

**第一～四篇成文于该规范建立之前**，因此它们的关键字义表只标出处（如"《破译》p.XX 点评"），**未逐条标注推演程度**；第五篇起才开始出现"本文推演，信心 med"一类标记。

这不代表前四篇的结论可靠性较低——它们的出处同样逐条标明、同样经过复核；只是**呈现的颗粒度不同**。为保持已发布内容的稳定，我们**不回改前四篇正文**，在此统一说明时代背景。后续新篇一律采用新规范。

### （1.5）一个必要的平衡：改动的字很少，但位置很关键

读者一路读下来，每篇都在讲"这个字改了、那个字其实不是那个意思"，容易形成一个印象：**这部书已经面目全非**。这个印象不准确。

- **已发布各篇中，有十篇原书明确未列任何勘误条目**（第十一、十六、十七、二十一、三十五、三十八、四十七、**五十五、五十六**篇，另第二十四篇因书影缺页而不确定）；⚠ **其中第五十五篇虽无勘误，却有两段逐字解密与整句译文，是德经中材料最厚的几章之一——「没有勘误」不等于「没有材料」**；其中**第三十五篇更是勘定本与整理者释文完全一致**——根本没有分歧可勘，**第四十七篇则是勘误与注疏俱无**；（另第四十五篇虽未列勘误条目，却出了一条注疏，故不计入）
- 即便在有勘误的章里，改动的也只是几个字；
- 上面第六节那张改字速查表，累计六十余条、覆盖四十章——**平均每章一到两个字**。

**那为什么读起来变化那么大？** 因为被改的那少数几个字，往往正是句子的枢纽——「不」「之」「爲」「死」「善」这类高频而承担关键语义的字。

> **改动的字很少，但改动的位置很关键。**
> 前半句提醒不要以为这是一部被重写的书；后半句提醒不要以为改动无关紧要。**两句都要听。**

### （2）本系列如实记录六类"不确定"

读者会在各篇中频繁看到"存疑""须回到原始图版核定""两读并存"一类标注。它们**不是同一回事**，分六类：

**第一类：字形未定——需要图版才能裁断**

| 位置 | 待定内容 |
|---|---|
| 第八篇 | 「中气」（帛书甲本）／「冲气」（勘定本） |
| 第十四篇 | ◆（从弓从壐）的字形 |
| 第十九篇 | ▲（从艮从寸）的字形 |
| 第五篇、第十五篇 | 「閳」字（干氏勘定用字，他本作"聞"／"爲"，原书无注疏） |
| 第二十二篇 | ■（門・二・心）与 □（門・口・心）的字形 |

**第二类：两说并存——证据不足以择一**

| 位置 | 待定内容 |
|---|---|
| 第十一篇 | 「費」——他在第五篇训作正面词，本章语境却要求负面结果，两读并存 |
| 第二十篇 | 「弗」训辅佐，只有一句有直接依据，推及另两句则句子不通 |
| 第二十篇 | 句末「也」训作实词，同样只有一句有明训 |
| 第二十二篇 | ■ 指"大脑意识层中的特殊阴阳变化"，但**为何要"塞住"它，原书未说明**，本系列不代补 |
| 第二十三篇 | 「襲常」原书未直译，本文按其字例推演 |
| 第二十八篇 | ✵ 字**只给了"关乎人体生命"这一范围，未给功能义**；三部件的布局原书亦未说明 |
| 第二十八篇 | 「坐其」之后勘定本无对应之字（传世本作"锐"），本文不补 |
| **第四十五篇／第五十一篇** | ⚠ **「死」字两读**：第四十五篇读作「不动」（「定」的意识状态，正面），第五十一篇读作「毁败」（负面）。两处句法环境不同（重死／必死），本系列并存不调和 |
| **第五十一篇／第五十二篇** | ⚠ **「天」字两读**：第五十一篇读作「自然之天」，第五十二篇读作「意识」。**两读都不是原书为该章写下的明训，均系本系列按体系判定**，故不择一 |
| **第五十篇／第五十三篇** | ⚠ **「不敢」两读**：第五十篇读作「进取」（不＝语助，有原书明训），第五十三篇读作真否定（无明训，按句法判）。**两读的适用边界原书未交代**，本系列并存不调和 |
| **第五十三篇／第五十四篇** | ⚠ **「兵」字两读**：第五十三篇读作兵器（本文按语境判），第五十四篇读作那种高功能的比喻（**有原书明训**）。两者依据强弱不对等 |
| **第三十七・三十八篇／第五十五篇** | ⚠ **「易」字两读**：前两篇按通行的「容易」读，第五十五篇按原书明训读作阴阳变化 |
| **第五十五篇／第五十六篇** | ⚠ **「也」字两读**：第五十五篇有原书直书，读作阴性事物；第五十六篇无直书，退回语气词。**判据是该章有无原书直书** |
| **第五十四篇** | ⚠ **「斤」有字义而无句法**：《说文》训斫木之斧是实录，但原书未交代它在句中充当什么成分。**本文的连缀信心很低，该篇正文明说「这一句现在确实读不通」** |

**第三类：作者本人材料前后不一——本系列不代为调和**

| 位置 | 内容 |
|---|---|
| **第十八篇** | ⚠ **《破译》主张原字是「夫」，《生命科学》径作「矢」且全未提「夫」**——同一位作者、同一字位、两个不同的正字 |
| 第十七篇 | 「民」训作气功修炼者，与他章"众潜能"的读法不同 |
| 第十七篇 | 「地」训作人体的代词，与他章"腹底"宽窄不同 |
| 第二十一篇 | 「知」训作大脑高功能的简称，与第十四篇"特异知感功能"所指的那一面不同；第三十篇又训作"知觉感觉"，**共三种** |
| 第三十三篇 | 「神」训作自然界的变化与发展，与第三篇「鼻息」不同 |
| **第三十篇** | ⚠ **同一部书内部前后不一**：◆ 字的构形，第十四章注疏作"从弓从壐"、第三十章注疏作"从彌从土"，而后者还注明"详见德经第14章" |
| **第四十三篇** | ⚠ **「浴」字两读**：第三、六篇训作「净化意识」（《破译》p.162 注疏／p.246 点评），本篇训作「水流、能量流之所汇」（《破译》p.184 注疏）——同一位作者、同一个字、两种读法，本系列并存不调和 |

**第四类：材料本身尚未到手**

| 位置 | 内容 |
|---|---|
| **第二十四篇** | ⚠ **所据书影该页未见勘误与注疏，且不能确定原书是否写在次页**——与第十一篇"已确认没有"性质不同，属**未知的空白** |

这一类与前三类的分别在于：前三类是**已知的问题**，第四类是**我们还没看到材料**。第二十四篇因此通篇标满"推演""待考""信心 low"，并在开头整段警示——**该篇不能用来支持或反驳这个体系的任何结论**。将来书影补齐，它要么被证实、要么被推翻，两种结果都是收获。

**第五类：作者本人主动标注的存疑**

| 位置 | 内容 |
|---|---|
| **第二十六篇** | ⚠ **✱ 字——干昌新自己用"可能是"表述，全书仅此一处**；他给的依据是《说文》未收、他书未见，属消极证据 |

这一类与前四类都不同：前四类是**我们**发现的问题，第五类是**作者自己标出来的**。它同时说明两件事——他分得清哪些有把握（**其余未加"可能"者，即其自认有把握者**），以及这是整套自造字主张最该被优先核验的一环。

**第六类：字位残缺——读法落在补出来的字上**

| 位置 | 内容 |
|---|---|
| **第四十八篇** | ⚠ **甲本 29 个字位中仅存「以」「為」二字，约九成残缺**——包括「天之道利而不害，人之道爲而弗爭」整句。「俞＝穴位」这条依据较强（双源）的注疏，**所依附的字位在甲本中并不存在** |
| 第四十七篇 | 甲本 28 字中 13 字残缺（近半）；「信言不美美言不信」前六字全无字位 |
| 第四十六篇 | 末句「至老死不相往来」七字在甲本中无字位 |

这一类与前五类都不同：**问题不在解释，而在底本本身**。勘定本此处依乙本与传世本补足——这是校勘学的常规做法，**但落在补字上的训释，其可核查性天然低于落在有字迹处的训释**。本系列在相关各篇正文中逐一标明，不放进脚注。

**为什么要把这些写出来。** 把缺口补齐、把矛盾抹平，文章会好看得多。但那样做等于**用不存在的证据支撑结论**。本系列的立场是：有几分依据说几分话，缺口留在原处，让后来者看得见问题在哪里。

其中第三类里第十八篇那一处最要紧——它**可以由帛书篆文影印图版直接检验**，不取决于谁的推理更漂亮。

### （3）本系列不作真伪裁断

干昌新的读法在学界之外，与主流《老子》研究的结论多有不同。本系列**只负责把这套读法完整、可核查地呈现出来**，逐条标明出处与依据强弱，**不对其真伪下判断，也不建议读者以其中所述现象为练习目标**。读者若要深究，宜回查原书与帛书图版。
