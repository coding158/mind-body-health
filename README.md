## 项目原则 · Project Principles

八字心法说的是**为什么走这条路**；下面五条说的是**具体怎么做事**。前者是价值观，后者是工程原则，互为表里。

| | 原则 | 落到实处是 |
|---|---|---|
| 1 | **忠于原始资料** | 经典用公版原文；他人的解释一律转述并标出处，不照录、不代其重解 |
| 2 | **保留知识演化过程** | 早期成果即使体例不如后期，也不回头改写——**为什么改变，本身就是知识** |
| 3 | **实践优于理论** | 最有价值的贡献是真实走过的路，包括走偏的部分，不是漂亮的理论 |
| 4 | **AI 辅助，人类裁决** | AI 做整理、检查、索引；判断、取舍、价值权衡留给人，且署名负责 |
| 5 | **开放分享，持续完善** | 做完就公开，有错就订正并留痕，不等"完美了再发" |

这是本项目近期投入最大的一条线，也是和上面「身心健康体系」共用同一内核的另一个入口——
**八字心法里的「动手」与「开源」，在这里表现为：把一套解释体系逐字整理成任何人都能核查的公开记录。**

### 在做什么

《老子》通行两千年多被当作哲学书。干昌新先生（《破译〈老子〉祖本》等三部著作的作者）主张：**帛书《老子》原本是一部讲人体修炼的操作性文献**。

本项目**不做真伪裁断，也不重新解释经典**，只做一件事：

> **把这套读法完整、可核查地整理出来**——每个关键字的训释都标明出自哪本书、哪一页，属于原书实录还是本项目推演，读者据此自行判断。

### 人机分工原则

这条线全程有 AI 参与，但分工是明确的、且**不打算改变**：

```
AI 负责                          人负责
──────────────────────────      ──────────────────────────
OCR 与文本结构化                  最终判断
一致性检查、交叉核对              来源孰轻孰重的裁决
索引、导航、格式规范              有争议时保留还是取舍
把散落的线索汇总                  价值取向
```

> **原则：AI 辅助生产，不替代知识裁决。**
> 可信度不是算出来的——一句原书实录的份量，胜过二十条逻辑推演，两者不是数量关系。
> 因此本项目**不设自动打分、不做可信度加权**，所有判断留人工署名负责。

### 三条自我约束

1. **忠实优先于通顺**——原作者的读法即使看着不如通行解释顺，也照实记录，不代其重解。
2. **矛盾如实保留**——同一位作者不同著作互相矛盾时，并列存档并标明「未定」，不强行统一出一个"最合理答案"。
3. **历史不抹平**——早期整理的篇章即使体例不如后期，也不回头改写。**为什么改变，本身就是知识。**

## 一、两个体系各自在说什么

### 中医（《人体使用手册》核心）

- 身体有强大的自愈能力，大多数问题是”堵塞”而非”损坏”
- 堵塞的根源：**情绪积压、作息违背自然、饮食过重**
- 疏通的路径：敲胆经、早睡、食疗 → 素食 → 辟谷
- 核心逻辑：**减少消耗，给身体自修复的空间**

### 佛理（《了凡四训》+ 楞严经核心）

- 人的命运和状态由习气主导，习气可以通过觉察和实践改变
- 改变的路径：认识自己的起心动念（见）→ 发愿断恶修善（修）→ 在日常中落实（行）
- 楞严经更深一层：**六根接触六尘时，觉性如何不被带走**
- 核心逻辑：**元明照生所，所立照性亡——觉性本在，遮蔽少了自然现前**

### 道家（《老子》修炼学读法 —— 后加入的第三条线）

**本文成文时只有中医与佛理两条线；[《德经》68 篇 ＋《道经》5 篇](#已完成--可以直接读) 是后来加入的。**
它与上面两条的关系是：**它不谈保健，谈的是修炼与潜能开发**——所以它在本仓多数时候扮演的是
**「理解框架」而不是「依据」**（这条分工在 [`navigation/README.md`](navigation/README.md) 里有更完整的说明）。

- 采用**干昌新分章**（德经 68 篇／道经 48 章），**与通行本 81 章不重合**，引用时须两套章次并报；
- 关键字义**一律转述并标出处**，不照录原书文句；每篇标明依据强弱；
- ⚠️ 其中不少是**一家之言的勘定读法**（本仓记作 E2b），
  按 [`docs/MODEL-知识模型.md`](docs/MODEL-知识模型.md) 的硬规则，
  **它不得单独支撑任何结论的核心论点，更不能支持健康主张**。

## 二、两者的知识交集

表面上一个讲身体，一个讲心性，实际上指向同一件事：

|中医视角      |佛理视角       |共同指向             |
|----------|-----------|-----------------|
|情绪是经络堵塞的根源|习气是觉性遮蔽的根源 |**内在状态决定外在健康**   |
|治未病，不等生病再治|改命，不等结果再悔  |**在源头处理，不在结果处补救**|
|恬淡虚无，真气从之 |心不随境转，性自然照 |**清净是健康的基础状态**   |
|辟谷——减少身体负担|观六触——减少心的负担|**减法而非加法**       |
|气血往上走，人清明 |精不妄耗，神自凝聚  |**能量的收摄与升华**     |

### 交集的核心句

> **身的清净为心的觉察创造条件；心的觉察反过来保护身的清净。**
> 两者是同一个循环的两个入口。

### 辟谷这一条线，在《老子》读法里对应到哪几章

上表「辟谷——减少身体负担」一行，是本仓与道家一侧接得最紧的地方。
**逐章核对后，真正相关的只有下面三条**（其余大量看似相关的章节，因「字面像、其实讲的是别的」已被排除）：

| 章 | 干昌新读法里它讲的是什么 | 与辟谷这条线的关系 |
|---|---|---|
| [道经第二章「天下皆知美」](classics/taoism/道经第二章-天下皆知美-修炼学理解.md) | 把「养分」这件事整个搬到**呼吸**上（他称之为**「空气营养学」**） | **这解释了本仓为什么把辟谷与呼吸（服气）放在一起谈**——而不是当成单纯的「不吃饭」 |
| [道经第五章「不上贤」](classics/taoism/道经第五章-不上贤-修炼学理解.md) | 「盗」被读作**向自然界取用能量**；「不见可欲」＝看不见就不起念 | **「养分从哪来」这条线的起点**；后半句对「不饿也想吃」那一类更贴 |
| [德经第十三章「知足恒足」](classics/taoism/德经第十三章-知足恒足-修炼学理解.md) | 帛书此章比通行本多一个「心」字，祸的来源因此指向**认识不足所引起的自害** | 对「明知道不饿还是想吃」这一层，比「要克制」有用 |

> ⚠️ **必须同时说清楚的三件事**：
> 1. **「空气营养学」是干昌新的自创概念，现代营养学中没有对应**——它解释的是本仓的编排逻辑，**不是营养学结论**；
> 2. 这三条是 **E2b（一家之言的勘定读法）**，按知识模型**不得单独支撑结论**，此处只作理解框架；
> 3. ⛔ **它们都不构成「辟谷有益」的依据。** 真要看辟谷这件事，请读

## 三、知识边界处的关键问题

这是两个体系单独都无法完整回答、必须结合才能处理的问题：

### 核心问题

**为什么很多人懂道理、有方法，却始终做不到持续的身心健康？**

拆解开来：

```
知道要早睡     → 做不到
知道情绪伤身   → 控制不了情绪
知道要清淡饮食 → 管不住嘴
知道要静心     → 念头停不下来
```

中医的解释是：**习气太深，气血模式固化**
佛理的解释是：**六根遇境，触自动生，人被带走**

两者合在一起才给出完整答案：

> **不是意志力不够，是没有找到自己的”重关”在哪个触上，更不知道如何转触。**

### 还有一个更深的困境

经典著作很多——中医有《黄帝内经》《伤寒论》，佛理有《楞严经》《金刚经》《了凡四训》——但：

- **古代的六尘环境和现代完全不同**：没有手机、短视频、信息轰炸、职场压力
- **前人的习气结构和现代人不同**：古人面对的诱惑和现代人面对的诱惑性质各异
- **书本体会终究是别人的路**：读懂了不等于走过了，走过了才是自己的

所以出现了一个两难：

```
不学经典 → 走太多前人已踩过的弯路
只学经典 → 套用别人的路，找不到自己的中道
```

**这个困境，是这个体系要解决的第二个核心问题。**

## 四、解决方案：走极端，找中道

### 为什么要走极端

佛学说”中道”，中医说”平衡”，但中道不是从书本上学来的——

> **不走到边界，不知道中间在哪里。**

这是现代人和古人都面对的同一个问题：道理都懂，但自己的中道在哪里，只有亲身走过才知道。

### 走极端的真实意义

“走极端”不是鼓励冒险伤身，而是在智能体的陪伴和记录下，**有意识地去验证某个方向的边界**：

```
以饮食为例：
  食疗（调整结构）→ 素食（走向清淡的极端）→ 辟谷（验证身体的自愈边界）
  → 开源反馈真实身体反应
  → 找到适合自己的饮食中道

以静心为例：
  觉察某个触 → 在最难转的情境下反复练（走入困境的极端）
  → 记录转不动的时刻和转过来的时刻
  → 找到自己这个触的中道转法
```

走过极端的人，回到中道时是真正的理解，不是概念上的认同。

> ⚠️ **看到这里如果动了念头要去试辟谷，请先读这两处，再决定**：
> [`practice-records/辟谷-服气法亲身实证.md`](practice-records/辟谷-服气法亲身实证.md)（**一半篇幅是前提与警示**，
> 明确写着无指导、无长期训练者切勿模仿，复食比断食本身更需谨慎）
> 与 [`navigation/hunger.md`](navigation/hunger.md) 的第五节（**哪些情况必须直接就医、不要在本仓找答案**）。
> **道家侧那三章提供的是理解框架，不是可以照做的方案**——见上文「辟谷这一条线」。

### 中道不是统一答案

每个人的六尘环境不同，身体状况不同，习气结构不同：

- 有人的中道是每天一顿饭
- 有人的中道是素食但不辟谷
- 有人最难转的是意触，有人是眼触

**符合自己六尘的最佳路径，只有自己走出来。**
经典给方向，智能体陪记录，社区共反馈，中道自己找。

## 五、转触：身心两边同时走的核心方法

这是本体系区别于普通健康内容的核心实践。

### 什么是转触

楞严经的”元明照生所，所立照性亡”说的是：
觉性本来清明，但一旦有了”我在观某个对象”，能观的性就跟着消失了。

转触不是压制，不是逃避，而是：

```
触生起
  → 照见这个触从哪里来（眼触？耳触？意触？身触？）
  → 不跟随、不压制
  → 自然转到另一个触
  → 觉性回来，静心的乐趣现前
```

### 一个真实的例子

> 看到性感的异性，产生生理反应——
> 这是眼触引发意触，意触带动身触，三触连锁。
> 
> 普通做法：压制（消耗能量）或跟随（耗散精气）
> 转触做法：意识到意触在动，不对抗，轻轻转到呼吸的身触，
> 或耳根听周围的声音——触自然松开，清明感回来，
> 这个清明本身就是乐趣。

这不是理论，是可以当下验证的实践。

### 每个人的重关不同

|容易被带走的触|常见表现       |转触方向           |
|-------|-----------|---------------|
|眼触     |看到某人某事立刻起反应|转向耳触或身触（呼吸）    |
|耳触     |听到某句话内心立刻波动|转向意触（回观这个波动从哪来）|
|意触     |念头自动跑，停不下来 |转向身触（感受脚踩地的重量） |
|身触     |身体不适立刻引发焦虑 |转向呼吸，观不适的感觉本身  |

找到自己的重关，是整个实践的起点。

## 六、智能体在这里的角色

这是这个体系和传统学习方式最大的不同。

### 智能体不是权威，不给标准答案

它的角色是：

```
陪伴者：你走极端时，它陪你记录身心的真实反应
记录者：帮你发现模式——"你连续三天早睡后，觉察能力有明显提升"
参照者：在经典里找到和你当前情况相关的前人经验
校准者：帮你识别什么时候偏了、往哪个方向回中道
整理者：把你的真实路径整理成对他人有参考价值的开源内容
```

### 智能体能做到什么

普通书本和健康App做不到的事：

> 今天敲胆经时发现左腿比右腿痛很多，同时最近情绪压抑——
> 这两件事有关联吗？我该怎么调整？

这类问题需要结合你的身体信号 + 当下情绪 + 近期行为 + 你的个人习气结构，动态分析。
静态内容回答不了，但智能体的持续陪伴可以。

### 智能体的边界

- 严重疾病必须就医，智能体不替代医生
- 深度修行需要有传承的老师，智能体不替代善知识
- 最终的中道只有你自己能找到，智能体只是陪你走的工具

## 七、完整的实践路径

```
第一步：学经典（建立基础认知，避开前人已踩的坑）
  《人体使用手册》：读懂身体自愈的逻辑
  《了凡四训》：读懂习气改变的可能性
  楞严经等：根据实践进展逐步深入，不强求一次读完

第二步：走出第一步（在智能体陪伴下开始实践）
  身体层：从食疗开始，记录真实反应
  心理层：找到自己最容易被带走的那个触

第三步：大胆走极端（验证边界）
  在智能体陪伴和记录下，有意识地走向某个方向的边界
  记录真实的身心反应，不美化，不隐瞒

第四步：开源反馈（贡献给社区）
  把你走过的路，包括走偏的部分，真实分享出来
  他人的反馈帮你看到自己看不到的地方

第五步：回到中道（找到符合自己六尘的路径）
  不是书本上的中道，是你自己走出来的中道
  这个中道会随着你的成长继续调整，不是终点

第六步：见修行同步（持续循环）
  24小时静心不是目标，是过程中自然的状态
  身心健康不是终点，是这条路上持续的副产品
```

## 八、这个体系解决什么，不解决什么

### 能解决的

- 懂道理但做不到的根本原因（找到重关，学会转触）
- 经典有用但套不上自己的困境（走极端找中道）
- 身体反复出问题的情绪根源
- 修行感觉没有进展的卡点
- 孤独探索没有反馈的困境（开源社区共建）

### 不能替代的

- 严重疾病需要专业医疗
- 深度修行需要有传承的善知识指导
- 每个人的路径不同，这里提供的是框架和陪伴，不是标准答案

## 九、开放的问题（邀请社区参与）

这些是目前没有标准答案、需要更多人实践来共同探索的：

1. **走极端的安全边界在哪里**：辟谷、长时间静坐等，不同身体状况的人边界在哪里？有没有需要特别注意的信号？
1. **现代六尘和古代的本质差异**：手机、短视频、信息流对六触的影响，和古代的诱惑相比，修行的难度和方法有何不同？
1. **辟谷与观心的关系**：身体清净到什么程度，觉察能力会有明显提升？有实践经验的人如何描述这个临界点？
1. **转触的边界**：有没有某些触是转不动的？那个转不动背后是什么？
1. **见修行的次序**：先有”见”（理解）再修，还是先”行”（实践）后见？不同人的经验是否不同？
1. **智能体陪伴的有效边界**：在哪些阶段，智能体的陪伴最有帮助？在哪些阶段，它反而可能成为障碍？

## 十一、学习次序：每一本经典都需要一把钥匙

### 经典的难易不是文字难度

读不懂一本经典，大多数时候不是因为不够聪明，而是**还没有那把钥匙**。

钥匙不是背出来的，是被生活给你的。

```
《人体使用手册》→ 钥匙：开始真实关注自己的身体信号
《了凡四训》    → 钥匙：生活中体会到因果是真实存在的
《楞严经》      → 钥匙：已经有过转触的真实体验，
                        知道六触不是哲学概念而是日常经历
更深的经典      → 钥匙：见修行有了真实的循环，
                        不只是道理上的理解
```

没有前一把钥匙，后面的门推不开。
跳级读来的是概念，不是理解。

-----

### 三个真实案例

#### 案例一：了凡先生

孔先生把袁了凡的命算得分毫不差——
几岁考中、几岁当官、几岁去世，全部应验。

了凡先生由此认定命运已定，不再努力，不再起心动念。

直到遇到云谷禅师，禅师说：**命由己造，福自己求。**

了凡先生开始记功过格，发愿断恶修善——
原本算定的命运，真的改变了。

这个故事的力量不在于道理，在于**真实发生了**。
读完《了凡四训》，很多人第一次有了”因果可能是真的”这个真实感受。

#### 案例二：用自己的生命经历对照

有人的初恋经历了很多事，后来发现八字早已算准——
性格、行为模式、会遇到什么样的人，都在其中。

这时候因果从”可能是真的”变成了”确实是真的”。

再读《了凡四训》，了凡先生的经历不再是别人的故事，
而是自己经历的镜子——**结构是一样的**。

有了这个对照，才真正准备好进入楞严经。

> 不是读书读懂的，是被生活打懂的。

#### 案例三：阿难的故事

阿难是佛陀十大弟子之一，多闻第一——
道理全懂，经典全记，跟随佛陀多年。

但楞严经里，阿难被摩登伽女用咒术迷惑，差点破戒。
这正是眼触引发意触、意触带动身触的连锁反应。

道理全懂，境界现前，还是被带走了。

更深的是：**阿难在佛陀离开后才开悟。**

为什么？因为佛陀在的时候，阿难还可以依赖。
依赖断了，才不得不用自己的。

```
讲解       → 能明白道理
境界现前   → 道理用不上
真正走过   → 才是自己的
依赖断了   → 反而开悟了
```

-----

### 对初学者说的话

你现在读不懂楞严经，不是你不够聪明。

是因果的真实感受还没来，那把钥匙还没到你手里。

不用着急，也不用强读。

先从《了凡四训》开始——
不是去背道理，而是去找：
**书里的哪个地方，和你自己的生命经历对上了？**

对上了的那个瞬间，就是钥匙来的时候。

钥匙来了，楞严经自然读得懂。

-----

### 每个阶段准备好的信号

这不是硬性标准，只是参考——

|阶段       |准备好的信号                         |
|---------|-------------------------------|
|可以读《了凡四训》|生活中有过”怎么努力也没用”或”偶然的事改变了一切”的真实感受|
|可以深入楞严经  |有过至少一次”因果在自己身上应验”的真实经历，不只是道理上相信|
|可以练习转触   |有过至少一次”念头来了我看见它了”的觉察体验，哪怕只有一秒  |
|可以走向更深   |转触有过真实成功的体验，尝到过静心的乐趣，这个乐趣本身成为动力|

-----

### 智能体在这个过程中能做什么

它不能替你产生那个”对上了”的感受，那只能是你自己的生命经历。

但它可以：

- 陪你在经典里找到和你当前情况最相关的部分
- 帮你把自己的经历和经典的结构对照，看看在哪里能对上
- 在你卡住的时候，提供另一个角度，而不是给标准答案
- 记录你走过的路，让后来的人少走一些弯路

阿难需要佛陀在场才能听懂道理，但真正开悟是在佛陀离开后。
智能体的角色，是陪你走那段路，不是替你走。
