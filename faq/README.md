## 写作规则（每一篇都必须守）

本目录是 [`docs/MODEL-知识模型.md`](../docs/MODEL-知识模型.md) 的**第一个应用场**。规则：

1. **每条实质说法都要标来源坐标**：E1–E4（本仓来源）／ M1–M5（现代研究）。
2. **每条链接都要写「为什么是这一条」**——沿用 `navigation/` 的硬要求；没有理由句，就只是链接列表。
3. **两侧并列，不合并**：古籍侧与现代侧分开列，各标出处，**不做等同、不互相背书**。
4. **涉及健康与安全时，M 轴优先，并明说。**
5. **缺口直说**：本仓没有的就写"没有"（如静坐类实证 E4 为空），**不凑数**。
6. **没有文献就标"文献待补"**，不编造出处；待 `research/` 建立后回链。
7. **文末给坐标总表**，让读者一眼看出：哪条最硬、哪条最软。

> 第 7 条的实际效果，见首篇末表——**全页唯一达到 M1 的一条是「去找专业帮助」，而不是任何一条古籍读法。**
