# 按问题查 · 现代问题导航
# Navigation by Problem

> **这个目录只回答一件事：「我有某个具体的身体或情绪困扰，该读本仓的哪一篇？」**
>
> 本仓其余入口是按典籍、按章节组织的——适合系统阅读，不适合带着问题进来的人。这里补上后一条路。
>
> This directory answers one question: *"I have a specific problem — which page in this repository should I read?"*

---

## ⚠️ 先说清楚这个目录不是什么

**本仓不提供医疗建议，本目录尤其不是分诊表。**

- 这里链接的古籍解读，是**一套理解框架**，不是诊断依据，也不是治疗方案；
- 这里链接的实践记录，是**具名个人的亲身经历**，不是可复制的方案，其中几篇本身就带着「切勿模仿」的警示；
- **每一页的最后一节都是「什么时候该去看医生」，那一节的分量高于该页其余全部内容。**

**如果你正在经历持续的、影响生活的症状，请先看医生，再回来读这些。** 顺序不要颠倒。

## 每页的固定结构

```
一、你可能是这样的        ← 现象描述，不作诊断
二、本仓相关的条目        ← 每条必须附「为什么是这一条」
三、现代常见的解释路径    ← 与古籍并列呈现，不混为一谈
四、可以做的三件事        ← 低风险、不需要器械与指导的
五、⚠️ 什么时候该去看医生  ← 全页最重要的一节
```

**第二节的「为什么是这一条」是硬要求。** 没有理由句，这就只是一份链接列表——**而链接列表帮不了任何人。**

## 章号怎么对上的（给核对的人）

**本仓的《老子》系列采用干昌新的分章：德经 68 篇、道经 48 章**，与通行本的 81 章**不重合**：

- 通行本一章常被拆成两三章（例：通行本第 2 章 ＝ 本仓道经第二、三、四章）；
- 篇次与章号也不总是一致（德经 68 篇中有 27 篇不一致）。

**因此本目录的每一条链接，都是回查各篇所对应的通行本章次之后重新配对的，不是按通行本章号直接套的。**
若你发现某条指错了，那是配对出错，请提 Issue——**这类错误是这个目录最要命的错误。**

## 覆盖范围的老实话

**本仓的《老子》解读，主题是「修炼与潜能开发」，不是日常保健。**

这意味着：**很多现代困扰在这套材料里根本没有对应条目**，而少数看起来对得上的，往往是因为那一章讲的是别的事、只是恰好用了同一个字。**本目录已经排除了这类「字面像、其实不是」的配对。**

**真正撑得起这四页的，其实是三类材料：**

1. **中医部分**（[`classics/tcm/`](../classics/tcm/)）——**尤其是《黄帝内经·上古天真论》**，「食饮有节，起居有常，不妄作劳」一句同时落在三页上，**且是公版原文，可自行核对**；
2. **实证记录**（[`practice-records/`](../practice-records/)）——具名个人的长期亲历，带完整前提与警示；
3. **觉知与佛典部分**（[`docs/AWARENESS-觉知与六触.md`](../docs/AWARENESS-觉知与六触.md) 与 [`classics/buddhism/`](../classics/buddhism/)）——对情绪一类的困扰更直接。

> 🔴 **第 1 类是 2026-08-07 才补上的**——建这四页时只检索了道家部分与实证记录，**把 `classics/tcm/` 整个漏掉了**。
> **教训**：**建导航时按目录逐个走一遍，比按印象去搜靠谱。** 详见 [BOOKS-MAP.md](BOOKS-MAP.md) 第三节。

**《老子》各篇在这里多数扮演「理解框架」的角色，而不是「依据」。** 这个分工，各页都会再说一次。
