# 现代研究对照 · Research Notes
# 只被问题拉动，不主动铺

> **这个目录不是文献库。**
>
> 它只做一件事：**当 `faq/` 或 `navigation/` 的某一页欠了一条现代依据，就在这里还清那一条。**

---

## 三条规则

1. **按需生长，只被 FAQ / 导航拉动。**
   **不主动收集文献、不追求覆盖某个领域**——目录的规模应当等于"已还清的债"，不等于"读过的论文"。
2. **每条必须给证据等级 M1–M5，并写清为什么是这一级。**
   ⛔ **不因"系统综述"三个字就升到 M1**（等级取决于它**纳入了什么**）。见 [`docs/MODEL-知识模型.md`](../docs/MODEL-知识模型.md) 核心原则二：**不同来源的知识，不互相升级**。
3. **允许结论是「暂无证据」（M5）。** 写出"没有研究"与写出"有研究"同样有价值。

## 每条的固定结构

```
一、这条是为谁补的     ← 哪一页欠的债，回链
二、原始出处           ← 作者/年份/期刊/卷期/页码/DOI，逐项核过
三、这项研究做了什么   ← 设计、样本、方法
四、关键数字           ← 逐个标明出自原文何处
五、证据等级与理由     ← M几，为什么不是更高的一级
六、⛔ 不能用它支持什么 ← 最重要的一节
```

**第六节是硬要求。** 一条文献最容易出错的地方不是"引错了"，而是**"引对了，但被用来支持它支持不了的结论"**。
