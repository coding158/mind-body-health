## 四、四条铁律（违反任何一条，产出即作废）

### ① 转述，不照录

**经文用公版帛书／传世文本；干昌新的训释一律转述观点并标明出处，不照录其著作文句。**

- **可以原样引用的**：**公版古籍**——《说文解字》《说文解字注》《玉篇》《广韵》《韵会》《集韵》《方言》《尚书》《诗经》《孟子》《荀子》《本草纲目》等；
- **不可照录的**：**原书的译文、注释文句、评说段落**——**必须改写**；
- **底稿 §3.1/§3.2/§3.3 是实录，等于原文**，改写时不要贴近其句式。

### ② 「实践对照」单独标注，不混入原文含义

**每篇必须有一节「实践对照（Layer 4）」**，并在节首写明：**它不参与训释判定，也不回头影响上文任何结论。**

### ③ 缺口与不一致留在原处，不抹平

**每篇必须有一节「本篇如实记录的 N 处」。** **这是本系列的核心价值所在**——**不是把一套读法讲圆，而是把它的接缝标出来。**

### ④ 涉及读者身体安全的主张，本仓不保持中立

**本系列一贯不作真伪裁断——但这一条是例外。** 遇到可能被读成练法、且与已知生理学冲突的主张，**用 ⛔ 明确写出「本仓不采纳」并给出理由**，不要只作中性转述。**已有五例，见第六节 J。**

## 六、⭐ 复现问题清单——前十五章累积下来的十三类

**这是本页最有用的一节。每写一章，逐条过一遍。**

### A. 🔴 勘定本用字不见于任何一本（已发生 3 次）

**做法**：拿 §2.3 的勘定用字，逐字比对 §2.1 甲本、§2.2 乙本、传世本。
**若三本皆无此字**——**那是他的校改，不是复原**，而原书常把它表述成「传世本改了字」。

- **已发现**：第九章「蹱而俞出」（帛书两本均作「動」）；第十三章「冲善信」（甲作「予」，三本皆无「冲」）、「蹱善时」（**甲乙传世三本完全一致作「動」，根本不存在传世本的改动**）。
- **处理**：**不得列入 §五 改字速查表**；另立条目记入 §六（2）第七类；**并公允补两点**——帛书释文各家略有出入（若他另据别本，本仓未能核到）；**校改本身不是错误，问题只在被表述成「传世本改字」**。

### B. 形近字的释文校订争议——与 A 分开

**若勘定用字与三本用字是形近字**（木/扌、辵旁互异等），**他主张的是「释文认错了」而非「依训诂改字」**。
**这是可靠图版解决的正常校订争议，不要与 A 并为一谈。** 已有：第十四章 ▣（三本作「植/植/持」）、「述」（三本皆作「遂」）、✧（两本作「葆」）。
⚠ **但若甲、乙两本一致，主张释文有误的门槛更高，须点明。**

### C. 甲本孤证

**甲本与「乙本＋传世本」相左而他取甲本**——已有第十一章「芮」、第十二章「治」「静」、第十三章「不静」、第十四章无「能」字。
**处理**：列四栏表；说明「甲本最古」是有原则的取舍**但代价是承重读法只靠一个抄本**；**并注明图版终审未完成**。
⚠ **且这条原则并非处处一律**——第十章「縣→绵」他反采传世字形，**这个不对称要指出**。
✅ **反向的一处**：「芮」在第十一、十四两章**两次独立出现**，降低抄误可能——**这是少见的对他有利的内证，要照样写出来。**

### D. 关键推论没有字书举证

已有：第三章「相」、第四章「弗」、第八章「不」、第十章「不死」。
**判别**：该字的训释在原书里**只给结论、不给字书或文献例证**，而**整章方向由它决定**。→ 归 §六（2）**第四类**。

### E. 词性改读

**把虚词读成实词**：第四章「弗」（否定副词→实义动词）、第十二章「於」（介词→实词）、第十四章「自」（反身代词→器官系统名）。
**性质与 D 同类，一并归第四类**，并指出传统读法本无文义障碍。

### F. 递训（展转相训）

第十三章「尤，異也」＋「異，分也」→「尤＝分」。**每一步单看都有出处，连起来未必成立。**

### G. 一词多义由体系裁定

「天地」广狭二义（第八～十章狭义／第十一章广义）；「民」三义（德经＝众潜能／第五章＝广大民众／第十五章＝声人）。
**一词多义本身不是问题，问题是取义标准来自他的体系。** 遇到就登记。

### H. 循环风险：结论被当作依据用

第九章「老子是经络第一人」（《老子》文本无「经络」「穴位」字样）；第十章「玄牝」（用他对前几章的解释去论证老子的推想能力）。

### I. 消极证据

「《说文》未收、他书未见」**不能证明「是老子新造的」**，只能说明现存材料里没有。

### J. ⛔ 安全类主张（已有五例，本仓明确不采纳）

1. **穴位体呼吸可替代肺鼻呼吸**（第十二章）——经皮气体交换量极小；**任何以减少/抑制/停止呼吸为目标的练习都有危险**；
2. **疗效轶事**（第十二章）——且有选择性报告；
3. **把不良反应解释为「正在见效」**（第十二章）——使说法不可证伪，更会把该就医的症状拖成「过关反应」；
4. **颅缝处穴位开合吐纳**（第十五章）——成人颅缝已骨性愈合；**头部冲击性练习是公认高风险区**；
5. **以单细胞生物气体扩散类推体呼吸**（第十五章）——**该类比恰恰说明相反的事**，且以设问提出却被当作前提使用。

> **遇到新的同类主张，照此办理**：⛔ 标明不采纳 → 给出具体理由 → 若指向练法则加安全提示 → 挂 `faq/why-restless-when-still.md` 链接。
> **并每次补一句以免误伤**：**指出这些不否定他在该章的训诂工作，字义层与主张层要分开。**

### K. 自创字（第十四章起）——口径不可含糊

- **「自造字」与「非自造字」是两种强度完全不同的主张，严格分开**（混讲会虚增强度）；
- 🔴 **「书影确认」确认的是「他的著作这样印」，不是「老子造过这个字」**；
- 🔴 **编辑口径裁定不产生新事实**——第十五章 ❖ 的标记曾由存疑改为确认，**依据是决定按其体系呈现，不是新证据**；**且有一部现代大型字书收同构字形并判为「魄」的异体**；
- **占位符**：道经已用 **✤**（序1，从手从矢从豆）、**✧**（序2，从一从王从呆，与德经共用）、**❖**（序3，从示从白）、**▣**（非自造，扌＋直）。
  **新符号不得与德经 §五 已登记的 17 个冲突**——**用改动前的版本核对，不要在自己刚插入说明文字后再查**（本项目踩过一次）。

### L. 甲本残损登记

每章都要在 §六（2）**第六类**登记补字情况。**第十五章是迄今最严重的一章**（仅十余字可辨，乙本为唯一完整见证）。

### M. 原书内部不一致

第一章「噭」（两部著作所记流行本对字不同）；第十五章「无雌／为雌」（勘定本正文与逐字注释不一致）。→ 归 §六（2）**第一类**，**并存不择定**。

import io, os

def issep(s):
    t = s.strip().strip("|")

    if ".git" in root:

                continue
            if not fence and l.strip().startswith("|"):
                if not run:
                    start = i
                run.append(l)
            else:
                flush(); run = []
        flush()
print("headerless table fragments:", len(bad))
for x in bad:
    print("  ", x)

## 十、给接手者的三句话

1. **这个系列的价值不在于把一套读法讲圆，而在于把它的接缝一处不落地标出来。** 若某一章你写完发现「如实记录」一节没什么可写，**多半是漏看了，而不是真的没有。**
2. **字义层与主张层必须分开。** 他的训诂常常相当扎实（《说文》原文一查就有），**而整章立起来靠的往往不是这些字**——**这个分离几乎每章都出现，是本系列最该讲清楚的东西。**
3. **只有一处不保持中立：涉及读者身体安全时。** 其余一律并存两说、不代裁断。
