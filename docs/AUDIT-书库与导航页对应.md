## 0. 这份对应是怎么做出来的

**书库定位**：`新时代与灵修合集V1.1典藏版.exe` → `extract_all_books.py` → 本地 Obsidian Vault
`D:\Obsidian\xinshidai_library`　实测 **32 个分类 / 446 个 MD 文件**（含 README 与目录页；去重后 **412 本**入目录）。

**对应方法**——**不按书名猜**：

1. 对四页各自的主题词在**全文**检索（失眠/不寐、疲劳/倦怠、焦虑/忧虑、辟谷/断食/食欲…）；
2. 按命中量排名；
3. **逐条回查上下文**，剔除「字面像、其实不是」的伪匹配；
4. 按 `tools/generate_catalog.py` 的规则标注版权档 A / B / C。

**沿用本仓三条纪律**：

- 每一条必须写得出「**为什么是这一条**」——见 [`navigation/README.md`](../navigation/README.md) 的硬要求；
- **缺口留在原处，不抹平**；
- **版权分级决定能不能收录**——见 [`STRATEGY-内容架构与版权策略.md`](STRATEGY-内容架构与版权策略.md)。

## 1. 先说三条最要紧的结论

### ① 有料的几乎全是 🔴 C 类 → 只能做「馆外延伸阅读指引」，不能作为仓内条目

四页真正对得上的书（中医养生类、奥修文集、藏密、拜伦·凯蒂、Tara Brach…）**全部在版权期内**。
全库 412 本中 **A 类 5 本 / B 类 3 本 / C 类 404 本**——能进仓的只有**元数据与指引**，全文不可提交。

### ② `sleep.md` 的缺口，这个书库补不上——建议维持现状

库中讲失眠的确实有料，但**清一色是 C 类中医自疗书，且直接给方剂与穴位**（如「加味逍遥丸」）。
这与 [`navigation/sleep.md`](../navigation/sleep.md)「不提供医疗建议」、[`navigation/README.md`](../navigation/README.md)「本目录不是分诊表」**正面冲突**。

`sleep.md` 第六节写明补录条件是「**本仓真的收进了相关材料**」——这些书**既不可全文收录（版权），内容性质又不合（自疗方剂）**，**条件未成立**。

### ③ 白名单里的「黄帝内经」「庄子」实际不在库中；「奥修解金刚经」是标题陷阱

经查，库内真正的 A 类公版只有：`薄伽梵歌`、`巴巴吉传`、`480位禅宗大德悟道因缘(上/下)`、`碧岩录`。

⚠️ `奥修文集/002-老子道德经`、`011-奥修解金刚经`、`079-信心铭` —— **书名含公版经名，版权属奥修（C）**。
`generate_catalog.py` 用**精确标题白名单**已在脚本层防住（这正是 HOW-EXTRACTION 说「为什么不是关键词」的原因），**但人工挑书时极易踩**。

> **含义**：想用「可合规收录的公版原文」来补四页缺口，**在这个库里基本做不到**。
