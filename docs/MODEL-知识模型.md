# 知识模型 · Knowledge Model
# 这个仓库里的每一句话，来自哪里、能支持什么、冲突时怎么办

> **核心原则（一句话）**
>
> ## 不同来源的知识，应当保留各自的证据等级，不互相冒充。
>
> 本仓最大的价值不是"古籍指导现代生活"，而是**始终告诉读者：这句话来自哪里。**

## 1. 这个仓库有哪些类型的知识（Q1）

**两条独立坐标轴**，任何一条内容都同时有两个坐标——**不要把它们混成一个"可信度"分数**。

### 轴一 · E：本仓自身产出的知识来源层级

| 级 | 内容 | 可回溯性 | 典型位置 |
|---|---|---|---|
| **E1** | **古籍原文与校勘** —— 帛书甲乙本、通行本、异文对照、字形勘定 | **最高**（可逐字核原件影印/释文） | `classics/taoism/道德经第五章-版本对照.md`、各章页「原文」节 |
| **E2** | **解释体系原书观点**（如干昌新）——**忠实转述，页码可回溯** | 高（可查原书页码） | 各章页「关键字义」节，标注如《破译》p.247 |
| **E3** | **项目组整理、归纳、现代解释** —— 本仓自己的串讲、编排、原创分析 | 中（依赖论证质量） | 章页「义理串讲」、`navigation/` 各页、`SQ/`、本文件 |
| **E4** | **实践观察、案例、个人经验** —— 具名个人的亲身记录 | 较低（n=1，无对照） | `practice-records/` |

### 轴二 · M：现代研究证据等级

| 级 | 内容 |
|---|---|
| **M1** | 系统综述 / 临床指南 |
| **M2** | 随机对照试验 |
| **M3** | 观察性研究 |
| **M4** | 专家意见 / 机制推论 |
| **M5** | **暂无现代证据** |

### 轴三 · R：权利与可传播性（**独立轴，勿与证据混同**）

沿用 `tools/generate_catalog.py` 的既有分级：**🟢A 公版 / 🟡B 不确定 / 🔴C 版权期内**。

> **为什么必须独立成轴**：这是审计中的实证——**一本 🔴C 类现代著作可以承载 M1 级证据，一份 🟢A 类公版原文往往是 M5**。
> **"能不能公开全文"与"可信度多高"是两回事**，混为一谈会同时犯两种错。

## 2. 每一种知识来自哪里（Q2）· 标注写法

**任何一条实质性说法，都应能回答"这是 E几 / M几"。** 推荐标注块：

```
> 来源：E2（干昌新原书观点，《破译》p.247，忠实转述）
> 现代证据：M5（暂无直接研究）
> 适用：帮助理解该章读法；不构成健康建议
```

再如：

```
> 来源：无古籍对应
> 现代证据：M1（CBT-I，多国指南一线推荐）
> 适用：可作为慢性失眠的行动建议
```

**本仓已在实践的等价写法**（不必改造，认作同一体系即可）：

- 章页：「以下均为**观点转述**」＋页码 → 即 **E2**；「本章依据不算厚，本页照实说明」「原书零改笔、零注疏」→ **E2 弱**
- 导航页：🟢较充分／🟡部分相关／🔴几乎没有 → 覆盖度，非证据级；每条必附「**为什么是这一条**」→ 论证可核
- 导航页第三节「现代常见的解释路径」→ **M 轴内容**，与古籍**并列呈现**

## 3. 每一种知识能支持什么、不能支持什么（Q3）

**这一节是全文最要紧的一节。**

| 级 | ✅ 能支持 | ⛔ 不能支持 |
|---|---|---|
| **E1** | 「原文作何字」「某本与某本此处不同」 | 「因此应当这样做」——**校勘不产生行动建议** |
| **E2** | 「某家如何读这一句」 | 「这就是老子本意」（一家之言）；**更不能支持任何健康主张** |
| **E3** | 「本仓如何理解、如何编排」 | 冒充 E1/E2 的确定性；**不得把归纳讲成原文或原书观点** |
| **E4** | 「**某个具名的人**经历过什么」 | 「因此这有效」「你也可以这样」——**n=1、无对照、有幸存者偏差** |
| **M1–M2** | 健康与行为建议 | 超出研究人群与条件的外推 |
| **M3–M4** | 提示方向、生成假设 | 当作定论 |
| **M5** | **什么都不能支持** | **凡涉健康主张，M5 一律不得单独成立** |

### 三条硬规则

1. **E4 永不升级为 M。** 实践记录再多、再一致，也不会变成研究证据——**它只增加"有人这样经历过"的样本，不增加因果强度**。
2. **E1–E3 不产生健康建议。** 古籍读法是**理解框架**，不是依据（`navigation/README.md` 已明写此分工）。
3. **凡"可能致伤"的内容（断食、憋气、剧烈体感、停药），无论 E 几，一律附前提与警示，并优先给出就医/求助路径。**

## 4. 冲突时怎么办（Q4）· 并列，不合并

> **冲突不是要消除的瑕疵，冲突本身就是信息。**

| 冲突类型 | 处理 | 本仓既有先例 |
|---|---|---|
| **E2 内部**（同一解释体系两书打架、或作者自相矛盾） | **专列一节说清**，不塞进串讲含混带过 | 系列总目所记第十八篇「两书冲突」、第二十篇「内部不一致」 |
| **E2 与通行注家**（如「反者道之动」：反馈 vs 返归） | **两读并存，各标出处**，不裁断谁对 | 德经第七章页；`SQ/` 维度四已加注「此处取通行读法」 |
| **E（古籍）与 M（现代）** | **并列呈现，不混为一谈**，各标出处，让读者自己称量 | 导航页固定第三节的做法 |
| **⚠️ 涉及健康与安全时** | **M 轴优先，并明说。** 这是唯一一条"分高下"的规则 | `sleep.md`：「CBT-I…**比本仓任何一篇古籍解读都有用**」 |

**禁止的三种消解方式**：

- ❌ 「其实说的是一回事」——用模糊措辞把冲突抹平；
- ❌ 用现代研究去"证明"古籍（把 M 当作 E 的背书）；
- ❌ 用古籍去"补上"研究的空白（把 E 当作 M 的替代）。

> **缺口留在原处，不抹平。** 这是本仓一贯做法（`sleep.md` 整页就是这条原则的实例：核对后没有对应章节，就直说没有）。

## 6. 落到新模块上（供后续 `cases/` `faq/` `research/` `templates/` 采用）

- **`cases/`（E4）**：每则须含**具名或可追溯、完整前提、失败与中断也要记、明确"不建议模仿"边界**。
  **无这些的案例＝见证式内容（testimonial），本仓不收。**
- **`research/`（M）**：每条必须标 M1–M5，**并允许结论是「M5：暂无证据」**——写出"没有研究"与写出"有研究"同样有价值。
- **`faq/`（E3 为主）**：回答现代问题；凡触及健康，须给 M 轴信息与就医边界。
- **`templates/`（工具，非方案）**：只回答"**如果你已经在实践，可以记什么**"，
  **不回答"你该做什么"**——这正是本仓不设 `protocols/` 的原因：**目录名一旦写成「3天轻断食」，就等于推荐**。
